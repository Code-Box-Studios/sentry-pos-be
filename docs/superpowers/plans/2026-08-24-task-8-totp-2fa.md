## Task 4: Create `PreauthGuard`

**Files:**
- Create: `src/auth/guards/preauth.guard.ts`

**Interfaces:**
- Consumes: `JwtService` (from `@nestjs/jwt`); `ConfigService` (for `JWT_ACCESS_SECRET`); `UnauthorizedError` from `api-errors.ts`
- Produces: `PreauthGuard` — a NestJS guard that passes ONLY `kind:"preauth"` tokens; attaches `{ sub, kind }` onto `req.preauthUser`

**Design:** This guard does NOT extend `AuthGuard('jwt')` (that would reject preauth via the strategy). Instead it manually verifies the JWT, checks `kind === 'preauth'`, and rejects anything else. This is the only guard allowed to accept preauth tokens.

- [ ] **Step 1: Create the guard**

Create `src/auth/guards/preauth.guard.ts`:

```typescript
import { CanActivate, ExecutionContext, Injectable } from '@nestjs/common';
import { JwtService } from '@nestjs/jwt';
import { ConfigService } from '@nestjs/config';
import { UnauthorizedError } from '../../common/errors/api-errors';

export interface PreauthPayload {
  sub: string;
  kind: string;
  iat?: number;
  exp?: number;
}

/**
 * Guards TOTP setup and enable endpoints. Accepts ONLY tokens with
 * `kind: "preauth"`. Rejects access tokens (no `kind` field), expired tokens,
 * garbage tokens, and missing headers.
 *
 * Attaches the verified payload to `req.preauthUser` so the controller can
 * read the user id without re-verifying.
 */
@Injectable()
export class PreauthGuard implements CanActivate {
  private readonly secret: string;

  constructor(
    private readonly jwt: JwtService,
    config: ConfigService,
  ) {
    this.secret = config.getOrThrow<string>('JWT_ACCESS_SECRET');
  }

  canActivate(context: ExecutionContext): boolean {
    const req = context
      .switchToHttp()
      .getRequest<{ headers: { authorization?: string }; preauthUser?: PreauthPayload }>();

    const authHeader = req.headers.authorization;
    if (!authHeader?.startsWith('Bearer ')) {
      throw new UnauthorizedError('Pre-auth token required.');
    }

    const token = authHeader.slice(7);
    let payload: PreauthPayload;

    try {
      payload = this.jwt.verify<PreauthPayload>(token, { secret: this.secret });
    } catch {
      throw new UnauthorizedError('Invalid or expired pre-auth token.');
    }

    if (payload.kind !== 'preauth') {
      throw new UnauthorizedError('Pre-auth token required.');
    }

    req.preauthUser = payload;
    return true;
  }
}
```

## Task 5: Create `TotpService`

**Files:**
- Create: `src/auth/totp.service.ts`

**Interfaces:**
- Consumes:
  - `PrismaService` (raw) — reads/writes `user.totpPendingSecret`, `user.totpSecret`, `user.totpRecoveryCodes`
  - `hashSecret` / `verifySecret` from `../hashing`
  - `otplib` — `authenticator` from `otplib`
  - `crypto.randomBytes` — for recovery code generation
- Produces (all methods are `async`):
  - `generateSetup(userId: string): Promise<{ secret: string; otpauthUri: string }>` — generates a new TOTP secret via `authenticator.generateSecret()`, stores it in `user.totpPendingSecret`, returns secret + otpauth URI. Label: user's email. Issuer: `"Sentry POS"`.
  - `enableTotp(userId: string, code: string): Promise<{ recoveryCodes: string[] }>` — verifies `code` against `user.totpPendingSecret` (±1 window); on success moves `totpPendingSecret` → `totpSecret`, generates 8 random recovery codes (plaintext returned, argon2-hashed stored in `totpRecoveryCodes`). Throws `TotpInvalidError` on bad code.
  - `verifyTotp(userId: string, code: string): Promise<void>` — tries TOTP code (±1 window) against `user.totpSecret`; if that fails, tries each hashed recovery code; if a recovery code matches, removes that hash from the array (single-use). Throws `TotpInvalidError` if neither matches.

```typescript
import { Injectable } from '@nestjs/common';
import { randomBytes } from 'crypto';
import { authenticator } from 'otplib';
import { PrismaService } from '../prisma/prisma.service';
import { hashSecret, verifySecret } from './hashing';
import { TotpInvalidError } from '../common/errors/api-errors';

const RECOVERY_CODE_COUNT = 8;
const RECOVERY_CODE_BYTES = 10; // 20 hex chars per code
const ISSUER = 'Sentry POS';

/**
 * TOTP enrollment and verification (Task 8).
 *
 * Uses otplib `authenticator` (RFC 6238 TOTP). Recovery codes are random hex
 * strings stored as argon2id hashes; they are single-use (consumed on verify).
 */
@Injectable()
export class TotpService {
  constructor(private readonly raw: PrismaService) {}

  /**
   * Generate a new TOTP secret and store it as PENDING (not enrolled).
   * The pending secret does NOT affect Task 7's `totpSecret == null` check,
   * so login correctly continues to return `totpSetupRequired` until `enable`
   * is called.
   *
   * Returns the raw secret and an otpauth URI for QR-code display.
   */
  async generateSetup(
    userId: string,
  ): Promise<{ secret: string; otpauthUri: string }> {
    const user = await this.raw.user.findUniqueOrThrow({
      where: { id: userId },
    });

    const secret = authenticator.generateSecret();
    const otpauthUri = authenticator.keyuri(user.email, ISSUER, secret);

    await this.raw.user.update({
      where: { id: userId },
      data: { totpPendingSecret: secret },
    });

    return { secret, otpauthUri };
  }

  /**
   * Verify `code` against the pending secret, then activate TOTP:
   * - Moves `totpPendingSecret` → `totpSecret`
   * - Generates 8 one-time recovery codes (plaintext returned once, hashed at rest)
   *
   * Throws `TotpInvalidError` if the code is wrong or there is no pending secret.
   */
  async enableTotp(
    userId: string,
    code: string,
  ): Promise<{ recoveryCodes: string[] }> {
    const user = await this.raw.user.findUniqueOrThrow({
      where: { id: userId },
    });

    if (!user.totpPendingSecret) {
      throw new TotpInvalidError();
    }

    // Verify against pending secret with ±1 window
    authenticator.options = { window: 1 };
    const valid = authenticator.verify({
      token: code,
      secret: user.totpPendingSecret,
    });

    if (!valid) {
      throw new TotpInvalidError();
    }

    // Generate 8 plaintext recovery codes
    const plainCodes: string[] = Array.from({ length: RECOVERY_CODE_COUNT }, () =>
      randomBytes(RECOVERY_CODE_BYTES).toString('hex'),
    );

    // Hash each code for storage
    const hashedCodes = await Promise.all(plainCodes.map((c) => hashSecret(c)));

    // Activate: move pending → active, store hashed codes
    await this.raw.user.update({
      where: { id: userId },
      data: {
        totpSecret: user.totpPendingSecret,
        totpPendingSecret: null,
        totpRecoveryCodes: hashedCodes,
      },
    });

    return { recoveryCodes: plainCodes };
  }

  /**
   * Verify a TOTP code OR a recovery code against the enrolled user.
   * Recovery codes are single-use: the matching hash is removed on success.
   *
   * Throws `TotpInvalidError` if neither a TOTP code nor a recovery code matches.
   */
  async verifyTotp(userId: string, code: string): Promise<void> {
    const user = await this.raw.user.findUniqueOrThrow({
      where: { id: userId },
    });

    if (!user.totpSecret) {
      throw new TotpInvalidError();
    }

    // Try TOTP code first (±1 window)
    authenticator.options = { window: 1 };
    const totpValid = authenticator.verify({
      token: code,
      secret: user.totpSecret,
    });

    if (totpValid) {
      return; // success
    }

    // Try recovery codes (sequential, constant-ish work)
    const hashes = user.totpRecoveryCodes;
    for (let i = 0; i < hashes.length; i++) {
      const match = await verifySecret(hashes[i], code);
      if (match) {
        // Consume: remove matching hash from the array
        const remaining = [...hashes.slice(0, i), ...hashes.slice(i + 1)];
        await this.raw.user.update({
          where: { id: userId },
          data: { totpRecoveryCodes: remaining },
        });
        return; // success
      }
    }

    throw new TotpInvalidError();
  }
}
```

```typescript
import {
  Body,
  Controller,
  HttpCode,
  HttpStatus,
  Post,
  Req,
  UseGuards,
} from '@nestjs/common';
import { JwtService } from '@nestjs/jwt';
import { ConfigService } from '@nestjs/config';
import { AuthService, LoginResult } from './auth.service';
import { TotpService } from './totp.service';
import { LockoutService } from '../common/lockout/lockout.service';
import { LoginDto } from './dto/login.dto';
import { RefreshDto } from './dto/refresh.dto';
import { TotpEnableDto } from './dto/totp-enable.dto';
import { TotpVerifyDto } from './dto/totp-verify.dto';
import { PreauthGuard, PreauthPayload } from './guards/preauth.guard';
import { UnauthorizedError } from '../common/errors/api-errors';

interface RequestWithPreauth {
  preauthUser: PreauthPayload;
}

@Controller('auth')
export class AuthController {
  private readonly accessSecret: string;

  constructor(
    private readonly auth: AuthService,
    private readonly totp: TotpService,
    private readonly lockout: LockoutService,
    private readonly jwt: JwtService,
    config: ConfigService,
  ) {
    this.accessSecret = config.getOrThrow<string>('JWT_ACCESS_SECRET');
  }

  // ---------------------------------------------------------------------------
  // Password auth
  // ---------------------------------------------------------------------------

  @Post('login')
  login(@Body() dto: LoginDto): Promise<LoginResult> {
    return this.auth.login(dto.email, dto.password);
  }

  @Post('refresh')
  refresh(
    @Body() dto: RefreshDto,
  ): Promise<{ accessToken: string; refreshToken: string }> {
    return this.auth.refresh(dto.refreshToken);
  }

  @Post('logout')
  @HttpCode(HttpStatus.OK)
  async logout(@Body() dto: RefreshDto): Promise<{ ok: true }> {
    await this.auth.logout(dto.refreshToken);
    return { ok: true };
  }

  // ---------------------------------------------------------------------------
  // TOTP: setup (store pending secret)
  // ---------------------------------------------------------------------------

  /**
   * Accepts ONLY preauth tokens (via PreauthGuard). Returns otpauth URI + raw
   * secret for QR display. Stores secret as PENDING so Task 7's login contract
   * (totpSecret == null → setupRequired) is not broken until enable succeeds.
   */
  @Post('totp/setup')
  @UseGuards(PreauthGuard)
  setup(
    @Req() req: RequestWithPreauth,
  ): Promise<{ secret: string; otpauthUri: string }> {
    return this.totp.generateSetup(req.preauthUser.sub);
  }

  // ---------------------------------------------------------------------------
  // TOTP: enable (activate after user scans QR and confirms a code)
  // ---------------------------------------------------------------------------

  /**
   * Accepts ONLY preauth tokens (via PreauthGuard). Verifies the provided TOTP
   * code against the pending secret, then moves pending → active and generates
   * 8 one-time recovery codes returned ONCE in plaintext.
   */
  @Post('totp/enable')
  @UseGuards(PreauthGuard)
  enable(
    @Req() req: RequestWithPreauth,
    @Body() dto: TotpEnableDto,
  ): Promise<{ recoveryCodes: string[] }> {
    return this.totp.enableTotp(req.preauthUser.sub, dto.code);
  }

  // ---------------------------------------------------------------------------
  // TOTP: verify (exchange preauth + TOTP/recovery code for full token pair)
  // ---------------------------------------------------------------------------

  /**
   * Does NOT use PreauthGuard (token is in the body, not the Authorization
   * header). Manually verifies the JWT, enforces kind:"preauth", then verifies
   * the TOTP or recovery code. On success, mints a full access/refresh token
   * pair. Failed TOTP attempts count toward the login lockout.
   */
  @Post('totp/verify')
  async verify(
    @Body() dto: TotpVerifyDto,
  ): Promise<{ accessToken: string; refreshToken: string; role: string }> {
    // Manually verify the preauth JWT from the body
    let payload: { sub: string; kind?: string; role?: string };
    try {
      payload = this.jwt.verify<{ sub: string; kind?: string; role?: string }>(
        dto.preAuthToken,
        { secret: this.accessSecret },
      );
    } catch {
      throw new UnauthorizedError('Invalid or expired pre-auth token.');
    }

    if (payload.kind !== 'preauth') {
      throw new UnauthorizedError('Pre-auth token required.');
    }

    const userId = payload.sub;

    // Fetch user to get role (not in preauth payload, and for lockout check)
    const user = await this.auth['raw'].user.findUniqueOrThrow({
      where: { id: userId },
    });

    // Check lockout before attempting TOTP verification
    this.lockout.assertNotLocked(user, 'login');

    try {
      await this.totp.verifyTotp(userId, dto.code);
    } catch {
      // Record failure toward login lockout (this throws LoginInvalidError or LoginLockedError)
      await this.lockout.recordFailure(userId, 'login');
      // recordFailure always throws; this line is unreachable but satisfies control flow
      throw new UnauthorizedError();
    }

    // Success — reset lockout counter
    await this.lockout.recordSuccess(userId, 'login');

    // Mint full token pair
    const { accessToken, refreshToken } = await this.auth.mintTokenPair(
      userId,
      user.role,
    );

    return { accessToken, refreshToken, role: user.role };
  }
}
```

**One known risk:** The `verify` endpoint calls `this.lockout.recordFailure()` on TOTP failure, which throws `LoginInvalidError` (not `TotpInvalidError`). The test expects `totp_invalid`. Two options:
1. Catch the `LoginInvalidError` and re-throw `TotpInvalidError` — cleaner for the client
2. Let `LoginInvalidError` propagate — still a 401 but with code `login_invalid`

The spec says "failed TOTP attempts ride the login lockout counters" and the test asserts `totp_invalid`. **Resolution:** Call `recordFailure` only for its side effect of updating the counter, but throw `TotpInvalidError` to the client. This requires wrapping `recordFailure` differently.

**Fix for verify lockout flow:** The current `verify` handler catches the TOTP failure and calls `recordFailure()` which always throws. We need to:
1. Detect TOTP failure ourselves
2. Update the counter directly (or accept `LoginInvalidError` is thrown from `recordFailure`)
3. Return `TotpInvalidError` to the client

The cleanest approach: in `verify()`, catch `TotpInvalidError` from `verifyTotp`, call `lockout.recordFailure()` in a separate try/catch to update the counter (catching the thrown `LoginInvalidError`), then throw `TotpInvalidError`.

Updated `verify()` inner logic:
```typescript
try {
  await this.totp.verifyTotp(userId, dto.code);
} catch (err) {
  // Record failure toward lockout counter (updateOnly — swallow the thrown error)
  try {
    await this.lockout.recordFailure(userId, 'login');
  } catch {
    // recordFailure always throws LoginInvalidError/LoginLockedError;
    // we discard it and throw TotpInvalidError instead so the client
    // gets a stable `totp_invalid` code. The lockout side effect (DB update) has happened.
  }
  throw new TotpInvalidError();
}
```

This ensures: (1) counter is updated, (2) client gets `totp_invalid`, (3) if lockout triggers, the next call to `assertNotLocked` on the next login will catch it. Note: if `recordFailure` throws `LoginLockedError` (user is now locked), we still throw `TotpInvalidError` — the next login will check lockout via `assertNotLocked`. This is acceptable per the spec ("failed TOTP attempts ride the login lockout counters").

This fix is **already reflected** in the controller code block in Task 7 above — re-read the verify handler and apply the corrected pattern with nested try/catch.
